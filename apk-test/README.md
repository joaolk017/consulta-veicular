# Consulta Veicular 360 — APK de instalação para testes
O app Android abre https://consultaveicular360.com.br em um WebView controlado, com botão para navegador externo, atualização e tela de indisponibilidade. Versão de testes com assinatura de debug do Gradle. Não é a versão com Google Play Billing pronta para publicação; para compras da Google Play, ver o pacote de código Android/Billing separado e terminar as integrações, testes e credenciamento na Play Console. Não instalar como atualização sobre uma versão assinada por outra chave. O APK depende do servidor do site estar ativo.
